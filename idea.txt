What you are describing is essentially **targeted outbound lead generation for website modernization**: identify businesses in the UK, USA, Australia, France, and Germany that already have a Google Maps/Business Profile presence but have an outdated website, then approach them with a concrete modernization proposal.

# 17. One important correction about Claude Code

You mentioned:

> "Google Maps API or any Claude Code connector"

These are two different things.

**Claude Code is a development/coding agent.**

It isn't itself a business directory or a magic client database.

You can absolutely use Claude Code to help you **build the lead-generation/auditing system**, but the underlying business data should come from legitimate sources/APIs.

Google's current Places APIs are designed for searching place information, while Business Profile APIs are for managing businesses' own profiles and have eligibility/authorization requirements. ([Google for Developers][3])

So architect it like:

```text
Google Places API
        ↓
Business discovery
        ↓
Your Python backend
        ↓
Website crawler
        ↓
Lighthouse / PageSpeed
        ↓
SEO parser
        ↓
AI analysis
        ↓
PostgreSQL
        ↓
Lead dashboard
```

Not:

```text
Claude Code → magically find clients
```
